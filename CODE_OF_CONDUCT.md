# Code of Conduct

BananLoop is an open technical collaboration. We expect participants to communicate respectfully, focus on evidence, and make room for people with different levels of experience.

Harassment, personal attacks, threats, hate speech, publishing personal information, and sustained disruption are not acceptable.

When reviewing work, critique behavior, methods and reproducible outcomes rather than individuals. Debate is welcome; abuse is not.

Report conduct concerns privately to repository maintainers through an available private GitHub channel. Do not post private personal details in public issues. Maintainers may warn, remove contributions or restrict participation when necessary.
