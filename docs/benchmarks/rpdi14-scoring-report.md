# RPDI-14 blinded scoring report scaffold

`benchmarks/v02_full/report.py` builds a deterministic paired report from a frozen track manifest, a blinded score package, a signed independent scorer attestation, and a separate signed operator unblinding attestation. The package must contain every preregistered pair exactly once. Missing, failed, and excluded pairs remain visible in the report. Available receipts and derived resource totals are retained for failed and excluded pairs too; missing receipts are marked `UNKNOWN`. Accounting summaries that are internally inconsistent, unknown, or over the frozen arm caps are retained but excluded from the paired estimate. The report records an oriented benefit delta (positive favors BananLoop for either outcome direction), wins/ties/losses, the preregistered approximate interval, and an underpowered outcome where the minimum is not met.

This is report assembly scaffolding, not a benchmark runner or an authorization to run either arm. It does not execute code, call a model, assign tasks, or establish evaluator isolation. The scorer attestation authenticates the submitted blinded score package, but this module does not independently rerun the evaluator or prove that scores correspond to output artifacts. The report recomputes accounting summaries from hash-linked action receipts and checks each receipt chain's internal integrity and caps. It does not authenticate receipt issuers, pin the final receipt head in a separate trusted record, or prove that the provider emitted every billable action. Until those controls are integrated and independently reviewed, resource eligibility and scores are not sufficient evidence for a valid RPDI-14 benchmark result.

The unblinding document is intentionally separate from the blinded package and must be signed by a benchmark operator distinct from the independent scorer. The resulting report reveals arm labels; store it with the preregistration and signed evidence under access controls appropriate for the task data. No production or benchmark outcome is claimed by these files.
