# React Flow spike — BananLoop Galaxy

**Status:** source-only integration spike, **not built/tested here** because npm registry access was unavailable. The working, browser-verified prototype is at `../index.html` (standalone CSS+JS canvas).

## What this spike demonstrates

- `@xyflow/react` + React 19: draggable custom research nodes and AND/OR gates, wheel zoom, pan, fit, minimap, directional Engine edges.
- A separate local annotation layer: double-click for editable note; Arrow tool creates a visually distinct personal edge. These never mutate Engine topology.
- Three design themes with CSS tokens; a source-owned `Button` component patterned after shadcn's local-component approach (not an installed shadcn registry component).
- The displayed nodes/edges are **synthetic fixtures**. No API, authentication, mutation, SSE, or LLM calls.

## Run when npm is available

```bash
cd react-flow-spike
npm install
npm run dev
npm run build
```

Run typecheck/build before adoption. `npm install` and build were **not** run in the authoring environment because registry DNS lookup failed. Versions are intentionally semver ranges; lock versions when implementing the production UI.
