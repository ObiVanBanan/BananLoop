# BananLoop test projects

Snapshots of four projects used in BananLoop QA campaigns. These are project fixtures, including their source data and evaluator code where present.

- `bananloop-bank-marketing`: UCI Bank Marketing project. Includes frozen validation and holdout CSVs under `.bananloop_eval/`, alongside train/dev data and evaluator code.
- `bananloop-playground`: synthetic Russian product matching fixture.
- `BananLoop-pr47`: BananLoop PR 47 checkout used for QA.
- `bananloop-wine-quality`: WineQT ML case study and its committed outputs.

Git metadata, Python environments, and bytecode caches are excluded. The validation and holdout splits are currently available for Bank Marketing only.
