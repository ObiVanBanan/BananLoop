# Test datasets

This directory collects the input data used in BananLoop real-project and dogfood runs. CSV files are copied/generated from the local project checkouts; the evaluation splits are included for reproducibility.

## Contents

- `bananloop-bank-marketing/`: chronological UCI Bank Marketing splits. `train.csv`, `dev.csv`, `validation.csv`, and `holdout.csv` are provided with the source `metadata.json`. Validation and holdout are frozen evaluation splits; do not tune against holdout. The upstream project documents UCI attribution and CC BY 4.0: [UCI Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank%2Bmarketing).
- `bananloop-playground/`: product catalog and matching queries used by the fixed product-matching playground. These are the project fixture files.
- `bananloop-wine-quality/`: WineQT `WineQT.csv`, copied from the local case-study checkout. Its README identifies the Kaggle source and dataset details: [YasserH/wine-quality-dataset](https://www.kaggle.com/datasets/yasserh/wine-quality-dataset).
- `bananloop-pr47/`: deterministic synthetic classifier fixture generated by `BananLoop-pr47/examples/stdlib_classification/create_fixture.py` at source commit `f81b048e45f7919cc72ef13325896ff0354979c0`. `eval.csv` is the fixture's frozen evaluation split.

The test project code, evaluators, and campaign state are not duplicated here. See the corresponding source checkouts and QA reports for reproduction commands and context.
